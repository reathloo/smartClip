# SmartClip v0.1.0-beta.2

This beta adds release protections: future version tags must point to the latest
tested `main` commit before the release workflow signs and publishes an update.

The app remains ad hoc signed and is not Apple notarized. On first launch,
follow [the installation instructions](https://github.com/reathloo/smartClip/blob/main/docs/INSTALLATION.md).

Requires an Apple Silicon Mac with macOS 14 or newer. The core clipboard
features are unchanged from beta.1.
