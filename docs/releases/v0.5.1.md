# SmartClip v0.5.1

SmartClip 0.5 makes the app and its project documentation accessible in five
languages and adds clearer ways to report problems, contribute changes, and
disclose security issues privately.

## App localization

- Use SmartClip in English, German, Simplified Chinese, Japanese, or Korean.
- Follow the preferred macOS app language automatically, including menu-bar
  actions, Settings, history controls, status messages, tooltips, and
  accessibility labels.
- Package and verify all five localization resources in release and UI-test
  builds.
- Support both SwiftPM resource-bundle layouts used by local macOS toolchains
  and GitHub-hosted release runners.

## Documentation and community support

- Add complete English, German, Simplified Chinese, Japanese, and Korean
  project guides with direct language navigation.
- Add contribution guidance, structured bug and feature forms, and a focused
  pull-request checklist.
- Add a security policy with private reports accepted at
  `security@jmakau.de`.

## Privacy and updates

SmartClip continues to keep clipboard data on the Mac. Clipboard payloads are
encrypted locally with AES-256-GCM, the encryption key remains in the macOS
Keychain, and the app has no telemetry or clipboard cloud synchronization.
Update packages are signed with the existing Sparkle EdDSA update key and
verified before installation.

## Requirements

- macOS 14 or newer
- Apple Silicon (M1 or newer)

## Installation note

This free release is ad hoc signed and is not Apple-notarized. On first
installation, allow SmartClip under **System Settings → Privacy & Security →
Open Anyway**. Existing installations can update through SmartClip's signed
automatic-update channel.
