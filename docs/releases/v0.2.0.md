# SmartClip v0.2.0

SmartClip 0.2 makes larger histories faster to use and adds a complete keyboard-first workflow while keeping clipboard data local and encrypted.

## New

- Open a full preview with Space without leaving the SmartClip window.
- Load older history in stable pages instead of loading the entire database at once.
- Copy, open, pin, preview, search, and delete selected entries with the keyboard.
- Drag text, URLs, images, and one or more file references into other apps.
- Optionally discard detected sensitive clipboard content instead of storing it.
- Set a storage limit, see current usage, and remove unpinned history while keeping favorites.

## Improved

- Database queries, decryption, and large-image decoding no longer run on the UI thread.
- History, preview, and settings now share one reusable window.
- Search stays unfocused until requested, avoiding the distracting blinking cursor.
- Sensitive previews are concealed again whenever the preview closes or the window loses focus.

## Privacy and updates

Clipboard payloads remain encrypted locally with an AES-GCM key stored in Keychain. SmartClip has no telemetry or cloud synchronization. Updates are delivered through the existing Sparkle feed and must match the EdDSA public key embedded in the app.

## Requirements

- macOS 14 or newer
- Apple Silicon (M1 or newer)

## Installation note

This free release is not signed with an Apple Developer ID and is not notarized. On first installation, allow SmartClip under **System Settings → Privacy & Security → Open Anyway**. Existing installations can update through SmartClip's signed automatic-update channel.
