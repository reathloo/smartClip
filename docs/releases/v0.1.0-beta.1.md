# SmartClip v0.1.0-beta.1

First public beta of the local, encrypted clipboard history for macOS.

## Included

- History for text, URLs, email addresses, images, files, and code
- Search, filters, list view, and card view
- Favorites and individual retention settings per entry
- Detection and masking for selected sensitive content
- Global keyboard shortcut, optional automatic paste, and launch at login
- Timed capture pause and excluded apps
- Signed automatic updates with a manual Check for Updates action
- Styled drag-to-Applications DMG

## Requirements

- macOS 14 or newer
- Apple Silicon (M1 or newer)

## Installation

The beta has no Apple Developer ID signature and is not notarized. On first launch, allow it under **System Settings → Privacy & Security → Open Anyway**. See [Install SmartClip](https://github.com/reathloo/smartClip/blob/main/docs/INSTALLATION.md) for the complete instructions.

## Known limitations

- The source app is an estimate. SmartClip does not inspect browser tabs.
- Files remain references to their originals.
- Code and sensitive-content detection use heuristics.
- Real permission, launch-at-login, and multiple-macOS-version checks remain open for this beta.
