# SmartClip v0.1.0-beta.1

Erste private Beta des lokalen, verschlüsselten Clipboard-Verlaufs für macOS.

## Enthalten

- Verlauf für Text, URLs, E-Mails, Bilder, Dateien und Code
- Suche, Filter, Listen- und Kartenansicht
- Favoriten und individuelle Löschfristen pro Eintrag
- Erkennung und Maskierung ausgewählter sensibler Inhalte
- globales Tastenkürzel, optionale direkte Einfügung und Autostart
- zeitgesteuerte Pause und ausgeschlossene Apps

## Voraussetzungen

- macOS 14 oder neuer
- Apple Silicon (M1 oder neuer)

## Installation

Die Beta ist nicht mit einer Apple Developer ID signiert und nicht notarisiert. Deshalb muss sie beim ersten Start über **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen** bestätigt werden. Die vollständige Anleitung steht unter [SmartClip installieren](https://github.com/reathloo/smartClip/blob/main/docs/INSTALLATION.md).

## Bekannte Grenzen

- Die Quell-App ist eine Schätzung; Browser-Tabs werden nicht ausgelesen.
- Dateien bleiben Referenzen auf ihre Originale.
- Code- und Sensitivitätserkennung arbeiten heuristisch.
- Die Systemtests für echte Berechtigungen, Autostart und mehrere macOS-Versionen sind vor der öffentlichen Freigabe noch manuell abzuschließen.
