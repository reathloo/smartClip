# SmartClip v0.3.0

SmartClip 0.3 adds encrypted entry notes and more flexible appearance options while strengthening the handling of concealed content.

## New

- Attach an optional encrypted note to any clipboard entry.
- Search regular entries by their note without changing the copied or dragged content.
- Choose between Light, Midnight, and the original Forest appearance.

## Improved

- Sensitive notes stay hidden from history and search until their entry is explicitly revealed.
- Sensitive preview data is discarded when the preview closes or the window loses focus, including delayed background loads.
- Cached multi-file drag handles are revoked immediately when an entry becomes sensitive.
- Notes count toward storage usage and are removed together with their entry.

## Privacy and updates

Clipboard payloads and entry notes remain encrypted locally with an AES-GCM key stored in Keychain. Notes are separate metadata and are never appended to copied or dragged content. SmartClip has no telemetry or cloud synchronization. Updates are delivered through the existing Sparkle feed and must match the EdDSA public key embedded in the app.

## Requirements

- macOS 14 or newer
- Apple Silicon (M1 or newer)

## Installation note

This free release is not signed with an Apple Developer ID and is not notarized. On first installation, allow SmartClip under **System Settings → Privacy & Security → Open Anyway**. Existing installations can update through SmartClip's signed automatic-update channel.
