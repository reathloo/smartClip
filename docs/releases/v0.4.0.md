# SmartClip v0.4.0

SmartClip 0.4 improves privacy detection, large-history performance, and the
macOS interface while keeping clipboard content local and encrypted.

## Privacy and filtering

- Detect common credential formats such as API keys, bearer tokens, private
  keys, and assigned secrets as sensitive clipboard content.
- Filter history specifically for sensitive entries.
- Keep sensitive payloads, notes, and favorite names concealed and exclude
  them from content search until an entry is explicitly revealed.
- Apply the existing sensitive-content storage policy to detected credentials.
- Reuse an existing immutable history key if two SmartClip processes attempt
  first-run Keychain creation at the same time.

## Performance and history workflow

- Filter time, source, favorite, type, and sensitive refinements in SQLite
  before decoding unrelated encrypted payloads.
- Downsample image thumbnails while decoding and reuse cached history IDs for
  navigation.
- Preserve scroll position when moving between history and Settings.
- Keep preview context, selection, and menu-bar reopening behavior consistent.
- Choose exact date and time or relative timestamps for history entries.

## Interface

- Add an optional experimental translucent interface with native frosted-glass
  surfaces for Light, Midnight, and Forest appearances.
- Match the window title bar to the selected appearance in both solid and
  translucent modes.
- Refine list grouping, card selection, hover feedback, and test-build status
  indicators.

## Security and updates

Clipboard payloads remain encrypted locally with AES-256-GCM. The encryption
key remains in the macOS Keychain, and SmartClip has no telemetry or clipboard
cloud synchronization. Update packages are signed with the existing Sparkle
EdDSA update key and verified before installation.

## Requirements

- macOS 14 or newer
- Apple Silicon (M1 or newer)

## Installation note

This free release is ad hoc signed and is not Apple-notarized. On first
installation, allow SmartClip under **System Settings → Privacy & Security →
Open Anyway**. Existing installations can update through SmartClip's signed
automatic-update channel.
