# SmartClip v0.3.2

This stable release contains the verified v0.3.1 feature set after the prior
tag could not publish because of a repository release-gate timing issue.

## Improved history workflow

- Refine history by time, source app, or favorites without decrypting entries
  that cannot match.
- File previews show the local file type, size, and modification date.
- Keep the visible capture time stable when an entry is copied again while its
  retention window is refreshed.
- Show a centered **Copied!** confirmation before the compact window closes.

## More reliable macOS integration

- Keep Sparkle update windows above the compact SmartClip panel.
- Open the menu-bar clipboard on the first left click.
- Add a clear return action at the bottom of Settings and a Permissions section
  for checking or restoring Accessibility access.

## Privacy and compatibility

As before, history stays encrypted and local. This update does not add accounts,
telemetry, or network access beyond the existing signed update feed.
